# Portfólio profissional — Stephany Chein

Site responsivo, minimalista e estático, desenvolvido em HTML, CSS e JavaScript. Não exige instalação nem servidor de aplicação.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para editar, abra a pasta no Visual Studio Code. Altere `index.html` (conteúdo), `styles.css` (visual) e `script.js` (menu mobile).

## Publicar grátis no GitHub Pages

1. Crie uma conta em https://github.com/ caso ainda não tenha.
2. Crie um repositório público chamado `portfolio-stephany`.
3. Envie os três arquivos (`index.html`, `styles.css`, `script.js`) **na raiz** do repositório. Você pode usar **Add file → Upload files** no próprio GitHub.
4. Acesse **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**. Escolha a branch `main` e a pasta `/(root)`; clique em **Save**.
5. Após a publicação, o endereço normalmente será `https://SEU-USUARIO.github.io/portfolio-stephany/` (substitua `SEU-USUARIO`). A ativação pode levar alguns minutos.
6. Adicione esse endereço ao LinkedIn e ao currículo.

## Alternativa: Netlify

1. Acesse https://app.netlify.com/drop e entre na conta, se solicitado.
2. Arraste a pasta descompactada do portfólio para a área de publicação.
3. Use o endereço público fornecido pela plataforma. As opções e a disponibilidade do plano gratuito podem mudar.

## Antes de compartilhar com recrutadores

- Confira nome, e-mail, localização, link do LinkedIn e datas.
- Confira se as atribuições da Bay Car Center e das outras experiências estão fiéis à sua trajetória.
- O projeto de automação de multas é apresentado como experiência realizada, sem código-fonte público.
- Os demais projetos estão claramente identificados como **planejados** ou **planejados**; não os apresente como entregues.
- Quando publicar projetos reais, acrescente links para GitHub e demonstrações.
- O site usa Google Fonts, mas possui fontes alternativas e funciona sem a conexão de fontes.

## Personalização rápida

- Cor principal: altere `--green` e `--dark` no começo de `styles.css`.
- Para acrescentar um projeto: copie um `<article class="project-card small">` na seção `#projetos`.
- Para acrescentar GitHub: insira um link externo na seção `#contato` quando sua conta estiver pronta.
